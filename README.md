Nome do jogo: O Enigma da Cabana
Membros: Laura Correia, Sophia Van Geem
Como jogo roda: O 'Enigma da Cabana' é um jogo de 'escape', em que o jogador está preso em uma cabana no meio da floresta. No início do jogo, o jogador se depara com um poema dando dicas de como prosseguir para poder escapar o primeiro cômodo da cabana, o quarto. Após outros desfaios a serem completos no quarto, o jogador segue para a cozinha onde encontra mais obstáculos e finalmente escapa a cabana.
